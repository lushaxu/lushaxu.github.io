High-Dimensional Data: From Factor Models to Deep Learning¶

Lusha Xu · UC Riverside · April 2026

The question: with many economic indicators, how do we extract signal to forecast GDP growth, inflation, or unemployment?

Three strategies for high-dimensional prediction:

strategy method
compression — summarize many predictors into a few components PCA / factor models
supervised compression — components built with the target in mind PLS
selection — keep only what matters Lasso
representation learning — let the model find nonlinear structure neural networks

1. Why high dimensions are hard¶

  • overfitting — the model fits noise instead of signal
  • multicollinearity — macro variables move together and repeat information
  • instability — OLS coefficients swing with correlated predictors
  • interpretation — hundreds of coefficients hide what matters
  • noise accumulation — irrelevant variables actively hurt

The problem is a balance: accuracy, interpretability, stability, feasibility.

The forecasting problem¶

Predict $y_{t+h}$ from a large predictor vector $X_t$.

Macro forecasting collects many indicators — unemployment, industrial production, payrolls, inflation, housing, sentiment — and they are not independent. They move together because a few broad forces drive them: the business cycle, financial conditions, inflation pressure.

Those hidden forces are latent factors: unobserved variables that influence many observed ones at once. When the economy weakens we see unemployment rise, production fall, sentiment drop, payroll growth slow — one force, many symptoms.

That co-movement is the whole intuition behind factor models and PCA: summarize the dataset with a few components instead of modeling every predictor separately.

In our simulation¶

Three persistent latent factors follow AR(1):

$$f_t = A f_{t-1} + u_t, \qquad f_t \in \mathbb{R}^3$$

60 observed indicators load on them:

$$X_t = \Lambda f_t + e_t$$

and the target depends on its own lag plus the factors, with one nonlinear term:

$$y_t = \phi y_{t-1} + (1-\phi)\left(1.5 f_{1t} - 1.0 f_{2t} + 0.7 f_{3t} + 0.4 f_{1t}^2\right) + \varepsilon_t$$

np.random.seed(42)

n_obs = 240          # e.g. 240 months
n_features = 60      # many predictors
n_factors_true = 3   # latent macro forces

# Generate AR(1) latent factors with persistence
ar_coeffs = [0.85, 0.7, 0.75]  # persistence parameters for each factor
F = np.zeros((n_obs, n_factors_true))

# Initialize
F[0, :] = np.random.normal(size=n_factors_true)

# Generate factors with temporal structure
for t in range(1, n_obs):
    for j in range(n_factors_true):
        F[t, j] = ar_coeffs[j] * F[t-1, j] + np.random.normal(scale=0.5)

# Factor loadings (how indicators load on factors)
loadings = np.random.normal(size=(n_features, n_factors_true))

# Generate observed predictors
X = F @ loadings.T + 0.3 * np.random.normal(size=(n_obs, n_features))

# Generate target with temporal structure
y = np.zeros(n_obs)
y[0] = (
    1.5 * F[0, 0]
    - 1.0 * F[0, 1]
    + 0.7 * F[0, 2]
    + 0.4 * (F[0, 0] ** 2)
    + 0.3 * np.random.normal()
)

# Add AR component to y itself (common in macro data)
y_ar_coeff = 0.4
for t in range(1, n_obs):
    y[t] = (
        y_ar_coeff * y[t-1] +  # AR(1) component
        (1 - y_ar_coeff) * (  # Factor-based component
            1.5 * F[t, 0]
            - 1.0 * F[t, 1]
            + 0.7 * F[t, 2]
            + 0.4 * (F[t, 0] ** 2)
        )
        + 0.3 * np.random.normal()
    )

# Create DataFrame
columns = [f"indicator_{i+1}" for i in range(n_features)]
df = pd.DataFrame(X, columns=columns)
df["target"] = y

2. Ordinary Least Squares¶

A natural starting point for forecasting is ordinary least squares (OLS) linear regression.

Model setup¶

Suppose we want to forecast a macroeconomic outcome such as GDP growth. Let

  • $y_{t+h}$ = the variable we want to predict at horizon $h$
  • $x_t = (x_{1t}, x_{2t}, \dots, x_{pt})^\top$ = predictors observed at time $t$

Then the forecasting regression is

$$y_{t+h} = \beta_0 + x_t^\top \beta + \varepsilon_{t+h}$$

Here:

  • $\beta_0$ is the intercept
  • $\beta = (\beta_1, \dots, \beta_p)^\top$ are slope coefficients
  • $\varepsilon_{t+h}$ is the forecast error

OLS minimizes the sum of squared residuals:

$$\min_{\beta_0,\beta} \sum_{t=1}^T \left(y_{t+h} - \beta_0 - x_t^\top \beta \right)^2$$

Forecast with $\hat{y}_{t+h} = \hat{\beta}_0 + x_t^\top \hat{\beta}$: estimate on history, plug in the latest predictors, evaluate out of sample.

Note: the target is persistent, so the code includes the lagged target as a predictor for every method. The equations show the standard form.

Matrix form¶

With $y = X\beta + \varepsilon$, the normal equations $X^\top X \hat{\beta} = X^\top y$ give

$$\hat{\beta}_{OLS} = (X^\top X)^{-1}X^\top y$$

Why many predictors break this¶

OLS needs $X^\top X$ invertible. It is singular or nearly singular when $p$ approaches $T$, when $p \geq T$, or when predictors are highly correlated — the columns no longer carry independent information.

$$\mathrm{Var}(\hat{\beta}\mid X) = \sigma^2 (X^\top X)^{-1}$$

Near-singularity blows this up: the coefficients become extremely noisy.

Intuition. With many similar predictors the model cannot decide which one deserves the weight, so small data changes swing the estimates. It fits history well and forecasts badly — overfitting.

2. Ordinary Linear Regression¶

A natural starting point for forecasting is ordinary least squares (OLS) linear regression.

Model setup¶

Suppose we want to forecast a macroeconomic outcome such as GDP growth. Let

  • $y_{t+h}$ = the variable we want to predict at horizon $h$
  • $x_t = (x_{1t}, x_{2t}, \dots, x_{pt})^\top$ = predictors observed at time $t$

Then the forecasting regression is

$$ y_{t+h} = \beta_0 + \beta_1 x_{1t} + \beta_2 x_{2t} + \cdots + \beta_p x_{pt} + \varepsilon_{t+h}. $$

In vector form,

$$ y_{t+h} = \beta_0 + x_t^\top \beta + \varepsilon_{t+h}. $$

Here:

  • $\beta_0$ is the intercept
  • $\beta = (\beta_1, \dots, \beta_p)^\top$ are slope coefficients
  • $\varepsilon_{t+h}$ is the forecast error
Note: In our simulated forecasting example, the target is persistent over time, so the code includes the lagged target \(y_t\) as an additional predictor when forecasting \(y_{t+1}\). For simplicity, the equations above present the standard form of each method. The same comment applies to the other methods as well, so we do not repeat it each time.

OLS chooses the coefficients that minimize the sum of squared residuals:

$$ \min_{\beta_0,\beta} \sum_{t=1}^T \left(y_{t+h} - \beta_0 - x_t^\top \beta \right)^2. $$

So OLS finds the linear relationship that best fits the training data in the least-squares sense.

In forecasting, we estimate the coefficients using historical data, then plug in the most recent predictors to generate a forecast:

$$ \hat{y_{t+h}} = \hat{\beta_0} + x_t^\top \hat{ \beta} $$

So the forecasting workflow is:

  1. Use past data $\{(x_t, y_{t+h})\}$ to estimate the model
  2. Obtain $\hat{\beta}_0$ and $\hat{\beta}$
  3. Use current predictors $x_t$ to compute the forecast $\hat{y}_{t+h}$
  4. Evaluate performance using out-of-sample forecasts

Matrix Form¶

Let the forecasting regression be

$$ y = X\beta + \varepsilon, $$

where

  • $y$ is the $T \times 1$ response vector
  • $X$ is the $T \times p$ predictor matrix
  • $\beta$ is the $p \times 1$ coefficient vector
  • $\varepsilon$ is the error term

OLS chooses $\hat{\beta}$ to minimize the sum of squared residuals:

$$ \hat{\beta}_{OLS} = \arg\min_{\beta} (y - X\beta)^\top (y - X\beta). $$

Taking the derivative and setting it equal to zero gives the normal equations:

$$ X^\top X \hat{\beta} = X^\top y. $$

If $X^\top X$ is invertible, the OLS solution is

$$ \hat{\beta}_{OLS} = (X^\top X)^{-1}X^\top y. $$

Why do too many predictors cause problems?¶

Theoretical reason¶

OLS requires $X^\top X$ to be invertible. This becomes problematic when:

  • the number of predictors $p$ is close to the number of observations $T$, or
  • some predictors are highly correlated, or
  • $p \geq T$

When $X^\top X$ is singular or nearly singular, it means the predictors do not provide enough independent information to identify a unique OLS solution, usually because some columns of $X$ are exact linear combinations of others. Also, variance of $\hat{\beta}$ becomes very large.

Variance formula is

$$ \mathrm{Var}(\hat{\beta}\mid X) = \sigma^2 (X^\top X)^{-1}. $$

If $X^\top X$ is close to singular, then $(X^\top X)^{-1}$ can contain very large values, which means the estimated coefficients become extremely noisy.

Intuition¶

With many similar predictors, the model cannot clearly decide which variable should get the weight. Small changes in the data can then lead to large changes in the estimated coefficients.

So even if the model fits the historical data very well, it often performs poorly on new data. This is overfitting.

Forecast error measures¶

Two common forecast error measures are:

  • MAE (Mean Absolute Error)
    $$ \text{MAE} = \frac{1}{n}\sum_{t=1}^n |\hat{y}_t - y_t| $$ MAE measures the average absolute size of the forecast errors. It tells us, on average, how far the forecasts are from the true values.

  • RMSE (Root Mean Squared Error)
    $$ \text{RMSE} = \sqrt{ \frac{1}{n} \sum_{t=1}^n (\hat{y}_t - y_t)^2 } $$ RMSE puts more weight on large mistakes because the errors are squared first. So RMSE is especially useful when large forecast misses are particularly undesirable.

In both cases, smaller values mean better forecasting performance.

Out-of-sample $R^2$¶

In forecasting, out-of-sample $R^2$ measures whether a model predicts future data better than a simple benchmark. It is commonly defined as

$$R^2_{OS} = 1-\frac{\sum_{t \in \text{test}} (y_t-\hat{y}_t)^2}{\sum_{t \in \text{test}} (y_t-\hat{y}_t^{(b)})^2}$$

where $\hat y_t$ is the model forecast and $\hat {y_t}^{(b)}$ is the benchmark forecast.

Common benchmarks include:

  • the training-sample mean, and
  • a simple autoregressive benchmark, such as AR(1), when the target is persistent over time.

A common interpretation is:

  • $R^2 > 0$: the model forecasts better than the benchmark
  • $R^2 = 0$: the model performs about the same as the benchmark
  • $R^2 < 0$: the model performs worse than the benchmark

Unlike in-sample $R^2$, this can be negative — and often is.

# ==================================================
# 2. Evaluation helper
# ==================================================
def evaluate_forecast(y_true, y_pred, y_train):
    rmse = mean_squared_error(y_true, y_pred) ** 0.5
    mae = mean_absolute_error(y_true, y_pred)
    r2 = r2_score(y_true, y_pred)

    # Out-of-sample R^2 relative to historical-mean benchmark
    y_bench = np.repeat(y_train.mean(), len(y_true))
    r2_os = 1 - np.sum((y_true - y_pred) ** 2) / np.sum((y_true - y_bench) ** 2)

    return rmse, mae, r2, r2_os

3. Principal Component Analysis¶

Principal Component Analysis (PCA) is a dimension reduction method that replaces many predictors with a smaller number of linear combinations called principal components.:

$$z_{kt} = w_k^\top x_t$$

where $w_k$ is a loading vector.

The first captures the most variation in the predictors; each next one captures the most of what's left while staying orthogonal to the earlier ones.

Variance-maximization view¶

The first principal component solves

$$ w_1 = \arg\max_{\|w\|=1} \operatorname{Var}(w^\top x_t). $$

The constraint $\|w\|=1$ prevents the solution from becoming arbitrarily large just by scaling up the weights.

The second solves

$$ w_2 = \arg\max_{\|w\|=1,\; w^\top w_1 = 0} \operatorname{Var}(w^\top x_t). $$

More generally, each component captures as much remaining variation as possible while staying orthogonal to earlier components.

Source: James, G., Witten, D., Hastie, T., & Tibshirani, R. (2021). An Introduction to Statistical Learning: With Applications in R (2nd ed.), Figure 6.14, p. 253. Book website.

Matrix view¶

For centered $X$ and unit vector $w$, the projection $z = Xw$ has variance proportional to $w^\top X^\top X w$, so

$$w_1 = \arg\max_{\|w\|=1} w^\top X^\top X w$$

Using a Lagrange multiplier, this leads to

$$ X^\top X w = \lambda w. $$

Thus, $w_1$ is the eigenvector of $X^\top X$ associated with the largest eigenvalue.
The first principal component scores are

$$ z_1 = X w_1. $$

More generally, the $k$-th principal component loading vector $w_k$ is the eigenvector corresponding to the $k$-th largest eigenvalue, with orthogonality to previous components.

Interpretation¶

Each principal component is a weighted average of the original predictors.

  • Loadings show how strongly each variable contributes to a component.
  • Scores show the value of that component for each observation.

In macroeconomics, principal components are often interpreted as broad latent forces such as overall activity, financial conditions, or inflation pressure.

PCA for forecasting¶

Step 1: Apply PCA to $X$ and keep the first $K$ components:

$$ F_t = (F_{1t}, F_{2t}, \dots, F_{Kt})^\top. $$

Step 2: regress the future target on them:

$$ y_{t+h} = \beta_0 + \beta^\top F_t + \varepsilon_{t+h}. $$

The limitation: PCA is unsupervised — it never looks at $y$. Directions that explain $X$ are not necessarily the ones that predict $y$.

4. Partial Least Squares¶

PLS is a supervised dimension reduction method: it builds components from the predictors while also using information from the response.

Similarly, PLS constructs components as linear combinations of the predictors:

$$t_k = X w_k$$

Objective¶

$$w_1 = \arg\max_{\|w\|=1} \operatorname{Cov}^2(Xw, y) = \arg\max_{\|w\|=1} (w^\top X^\top y)^2$$

It picks the direction whose component is most strongly associated with the target.

PLS vs PCA¶

$$w_1^{\text{PCA}} = \arg\max_{\|w\|=1} w^\top X^\top X w \qquad w_1^{\text{PLS}} = \arg\max_{\|w\|=1} (w^\top X^\top y)^2$$

PCA explains variation in $X$; PLS finds directions in $X$ that predict $y$.

So PCA is unsupervised, while PLS is supervised.

Deflation¶

After extracting a component, PLS removes the variation it explains and repeats on the residuals. This is called deflation.

For component $k$, we work with residual matrices $X_{k-1}$ and $y_{k-1}$, and construct

$$ t_k = X_{k-1} w_k. $$

Then we write

$$ X_{k-1} = t_k p_k^\top + E_k, $$$$ y_{k-1} = t_k q_k + f_k. $$

This process continues until we keep $K$ components.

Forecasting¶

$$y_{t+1} = \alpha_0 + \alpha^\top t_t + \varepsilon_{t+1}$$

Extract a few supervised components, then regress the future target on them. $t_t$ is the vector of PLS component scores for observation $t$.

Why can PLS lose to PCA?¶

Because it uses $y$ to build the components, PLS can fit noise in the training sample. PCA is less targeted but often more stable out of sample — when the main common variation in $X$ is what actually matters.

5. Sparse regression with Lasso¶

Motivation for sparse regression:

With a very large predictor set, it is more plausible that a small subset carries most of the signal than that every variable matters equally.

Lasso — Least Absolute Shrinkage and Selection Operator:

$$\min_{\beta_0,\beta} \left\{ \sum_{t=1}^T \left(y_{t+h}-\beta_0-x_t^\top\beta\right)^2 + \lambda \sum_{j=1}^p |\beta_j| \right\}$$

The first term is the usual fit term: it rewards the model for matching the data well.
The second term is the L1 penalty, which penalizes large absolute coefficient values.

Intuition

Lasso balances two goals:

  • fit the data well
  • keep the model simple

If $\lambda = 0$, Lasso reduces to ordinary least squares.
If $\lambda$ becomes larger, the penalty becomes stronger, and more coefficients are pulled toward zero.

Why it selects variables. The geometry of the L1 ball makes corner solutions likely, so the optimizer sets many $\hat{\beta}_j$ to exactly zero — automatic variable selection.

Source: Nicoguaro (2017), L1 and L2 balls, Wikimedia Commons. Licensed under CC BY 4.0.

Here, $\lambda \ge 0$ is a tuning parameter that controls the tradeoff between fit and sparsity.

  • small $\lambda$: weak penalty, more coefficients kept in the model
  • large $\lambda$: strong penalty, more coefficients shrunk to zero

So choosing $\lambda$ is very important. In practice, it is often selected by cross-validation or another validation procedure.

Workflow: standardize → choose $\lambda$ → estimate → forecast $\hat y_{t+1} = \hat\beta_0 + x_t^\top \hat\beta$.

Weaknesses

  • results hinge on $\lambda$
  • among correlated predictors it picks one and drops the rest somewhat arbitrarily
  • if the truth isn't sparse, it throws away useful information
  • still linear unless you add nonlinear features yourself

6. Neural networks¶

A neural network is a flexible prediction model that learns a nonlinear relationship between the predictors and the response:

$$ y_{t+1} = f(x_t) + \varepsilon_{t+1}, $$

where $f(\cdot)$ is a nonlinear function learned from the data.

One-hidden-layer neural network¶

Source: Generated by Chatgpt.

A simple feedforward neural network with one hidden layer can be written as

$$y_{t+1} = \beta_0 + \sum_{m=1}^M v_m \, \sigma(w_m^\top x_t + b_m) + \varepsilon_{t+1}$$

where:

  • $M$ is the number of hidden units,
  • $w_m \in \mathbb{R}^p$ is the weight vector for hidden unit $m$,
  • $b_m$ is the bias term for hidden unit $m$,
  • $v_m$ is the weight from hidden unit $m$ to the output,
  • $\sigma(\cdot)$ is an activation function.

Each hidden unit takes a linear combination $a_m = w_m^\top x_t + b_m$, applies a nonlinearity $h_m = \sigma(a_m)$; the output is a weighted sum of those units.

Activation functions

The activation function introduces nonlinearity into the model.

A common example is the ReLU activation:

$$ \sigma(a) = \max(0, a). $$

Without a nonlinear activation the whole network collapses to a linear model.

Compact form¶

$$h_t = \sigma(W x_t + b), \qquad \hat{y}_{t+1} = \beta_0 + v^\top h_t$$

The network first learns a representation of the predictors, then forecasts from it.

Deeper networks stack the step:

$$h_t^{(1)} = \sigma(W^{(1)} x_t + b^{(1)}), \quad h_t^{(2)} = \sigma(W^{(2)} h_t^{(1)} + b^{(2)}), \quad \dots$$

which is why these are called representation learning methods: they learn increasingly abstract transformations of the predictors.

Estimation¶

Neural networks are usually estimated by minimizing a loss function, such as mean squared error in regression:

$$ \min_{\theta} \sum_t \left(y_{t+1} - \hat{y}_{t+1}\right)^2, $$

where $\theta$ represents all network parameters: weights, biases, and output coefficients.

No closed form — gradient descent and its variants.

Limitations¶

Harder to interpret · sensitive to tuning · computationally heavier · prone to overfitting in small samples.

In macro settings they do not automatically beat simpler methods. Treat them as a flexible benchmark, not a default.

PCA regression wins — lowest RMSE and MAE, highest out-of-sample $R^2$. Summarizing the predictors into a few common components works well when the data really was generated by common factors.

AR(1) and Lasso come next and are close to each other: target persistence matters a lot, and a small sparse set captures most of the remaining signal.

PLS is respectable but doesn't beat PCA — supervised components overfit the training sample here.

Full OLS and the neural network trail. Using all predictors directly hurts in high dimensions, and the network doesn't recover enough nonlinear structure to justify its flexibility.

8. Which method, when?¶

PCA / factor models — predictors strongly correlated, common latent structure plausible, you want stable low-dimensional summaries, co-movement is the point.

PLS — prediction is the goal, predictors many and correlated, you want the reduction to be supervised.

Lasso — interpretability matters, many predictors are probably irrelevant, a sparse model is desirable.

Neural networks — nonlinear structure matters, data is plentiful, and the flexibility is worth the complexity.
